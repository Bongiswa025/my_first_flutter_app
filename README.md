# Flutter Namer App

## Project Overview

This is my first Flutter application, developed as part of my Flutter elective.

The project follows Google's *Your first Flutter app* codelab. It is a random word generator that allows users to generate word pairs, save their favorites, and remove words they no longer want.

## Technologies Used

- Flutter
- Dart
- Provider package
- English Words package
- Visual Studio Code
- Git and GitHub

## Features

- Generate random word pairs using the Next button.
- Like and unlike word pairs.
- View saved words on the Favorites page.
- Remove individual favorite words using a delete button.
- Navigate between Home and Favorites.
- Responsive navigation that adjusts to the available screen width.

## How to Run the Project

1. Install Flutter and set up your development environment.
2. Clone this repository:

   ```bash
   git clone https://github.com/Bongiswa025/my_first_flutter_app.git
   ```

3. Open the project directory:

   ```bash
   cd my_first_flutter_app
   ```

4. Install the required packages:

   ```bash
   flutter pub get
   ```

5. Run the application in Chrome:

   ```bash
   flutter run -d chrome
   ```
